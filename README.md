### 🎙️ ASR Benchmarking — Hindi / Hinglish
**Which speech model actually understands India?**

Ran a proper engineering study — not vibes, actual WER measurements — on **Deepgram Nova-2 · Whisper Large-v3 · Sarvam AI · AssemblyAI** against self-recorded Hinglish audio with real Indian accents and code-switching.

Key findings: Deepgram leads on accuracy. Sarvam wins on latency. **All four hallucinate on Bangalore locality names.** The full report lives in the repo.

`Python` `Deepgram` `Whisper` `Sarvam AI` `AssemblyAI`
